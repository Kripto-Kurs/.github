## Layihə Haqqında

Kripto-Kurs müasir riyazi kriptoqrafiya, informasiya təhlükəsizliyi protokolları, paylanmış reyestr texnologiyaları (blokçeyn) və post-kvant dayanıqlı sistemləri əhatə edən genişmiqyaslı açıq təhsil resursudur (Open Educational Resource - OER).

Kurs riyazi nəzəriyyə ilə tətbiqi proqramlaşdırma təcrübəsini birləşdirir: hər bir mövzu həm nəzəri riyazi bünövrə (qruplar, sonlu meydanlar, modulyar arifmetika, elliptik əyrilər), həm də təhlükəsizlik analizi və alqoritmik icra detalları ilə izah olunur.

## Kursun Mövzu Strukturu

```text
Kripto-Kurs Modulları
├── 01. Klassik Kriptoqrafiya və Tarixi Şifrlər (Sezar, Vigenère, Əvəzləmə)
├── 02. Müasir Simmetrik Blok və Axın Şifrləri (DES, 3DES, AES, ChaCha20, Modlar: CBC, CTR, GCM)
├── 03. Ədədlər Nəzəriyyəsi və Riyazi Bünövrə (Evklid, Eyler, Fermat, Modulyar Arifmetika)
├── 04. Asimmetrik (Açıq Açarlı) Şifrləmə (RSA, Diffie-Hellman, ElGamal)
├── 05. Elliptik Əyrilər Kriptoqrafiyası (ECC, ECDH, Ed25519)
├── 06. Rəqəmsal İmza və Açar Mübadiləsi (DSA, ECDSA, Schnorr)
├── 07. Kriptoqrafik Heş Funksiyaları və MAC (SHA-2, SHA-3, HMAC, Keccak)
├── 08. Sıfır Biliyi Sübutları (Zero-Knowledge Proofs — ZKP, zk-SNARKs, zk-STARKs)
├── 09. Post-Kvant Kriptoqrafiya (PQC — Lattice-based, ML-KEM, ML-DSA, SPHINCS+)
└── 10. Müasir Tətbiqlər və Blokçeyn (Bitcoin, Ethereum, Konsensus Mexanizmləri, MPC, FHE)
```

## Texnoloji Ekosistem

- **İnterfeys və Render:** Vanilla JavaScript SPA, MathJax (LaTeX və MathML riyazi render), Responsive CSS
- **Oflayn İcra:** Service Worker keşlənməsi, Web App Manifest
- **Bilik Bazası:** Markdown, Pandoc AST, əlaqəli daxili keçidlər və xülasə kataloqları
- **Hostinq və İnteqrasiya:** GitHub Pages avtomatik yerləşdirmə sistemi (GitHub Actions)
